Inbound Flow — Container to FIFO Layer

Triggered when goods arrive. Each Item Receipt line creates a FIFO cost layer capturing the full landed cost at that point in time.

EXW Cost Formula

Ex-Works cost per pound, calculated at the item level on each PO line.

EXW $/lb =
  LME 3-Month ($/lb, locked at PO creation from API)
  + MJP Premium ($/lb, Midwest Journal Premium)
  + Billet Surcharge ($/lb, item-level field) NEW
  + Conversion Cost ($/lb, from Hanwood price list)
  + Fabrication Cost ÷ Weight per Piece ($/piece → $/lb) NEW

DDP Cost Formula

Delivered Duty Paid — full landed cost including tariffs, duties, freight and misc charges.

Entered Value = Hanwood Invoice Price × Qty Received
⚠ Duties are calculated on Entered Value (vendor price), NOT on calculated EXW

DDP $/lb = EXW $/lb
  + Section 232 = Entered Value × 25% ÷ Total Weight
  + Duty = Entered Value × Duty Rate% ÷ Total Weight
  + Freight $/lb (container freight allocated by weight share)
  + Misc $/lb (customs broker fees + other charges by weight)

Sell Price Formula

Two-tier margin applied to DDP cost — EXW margin varies per customer/item, DDP margin fixed.

Sell Price $/lb =
  DDP $/lb
  × (1 + EXW Margin%) (varies: ~30-57% per customer/item)
  × (1 + DDP Margin%) (fixed: 7%)

Line Total = Sell Price $/lb × Weight per Piece × Qty

Outbound Flow — SO to Invoice with FIFO Consumption

When an SO is saved, the UE script looks up the latest FIFO layer for each item and calculates the sell price. Invoicing consumes layer quantity.

Container Operations — Distribute Freight

The Container record holds total freight and misc. The "Distribute Freight" button allocates these across all linked POs by weight share.

Line-Level Container Mapping

One SO can pull items from multiple containers. The container must be tracked at the line level, not just the header.
